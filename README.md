# Web Scraper

A small interactive Python tool that fetches a web page and prints its HTTP status, content type, and a short response-body preview.

## Requirements

- Python 3.10+
- `requests`

## Setup

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
```

## Run

```bash
python main.py
```

Enter a target URL beginning with `http://` or `https://` when prompted.
